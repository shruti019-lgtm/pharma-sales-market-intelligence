# Pharma Sales & Market Intelligence Project

## 📌 Objective
To analyze pharmaceutical sales data and generate market intelligence insights related to therapy performance and doctor visit timing.

---

## 🧾 Data Overview
- Granularity: Hourly sales data
- Records: ~50,000 rows
- Key fields:
  - Date & Hour
  - Therapy / Treatment Type
  - Sales Value
  - Time Block (Day / Night)

Raw data was cleaned and processed using Python before being summarized for analysis.

---

## 🛠 Tools & Technologies
- **Python (Google Colab):** Data cleaning, feature engineering
- **Excel:** Pivot tables, business logic validation
- **Tableau:** Interactive dashboard & story creation

---

## 📊 Key Analyses
1. **Therapy-wise Market Share (%)**
2. **Day vs Night Sales Distribution**
3. **Total Sales KPI**
4. Interactive filters for therapy and time block

---

## 📈 Key Insights
- A small number of therapies contribute a majority of total sales.
- Sales are significantly higher during Day (OPD) hours compared to Night (Non-OPD).
- Sales timing aligns strongly with doctor visit windows.
